# Startup Investment Analysis

## Overview
Analysis of startup investment data, funding rounds, acquisitions, and company outcomes.

## Objectives
- Analyze funding trends
- Compare company outcomes
- Study investment activity by category
- Identify patterns related to startup success

## Tools
Python, pandas, numpy, matplotlib, seaborn, SQL, Jupyter Notebook

## Workflow
1. Data exploration and cleaning
2. Funding analysis
3. Company outcome analysis
4. Visualization and insights
