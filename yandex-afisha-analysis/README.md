# Yandex Afisha Analysis

## Overview
Analysis of ticket sales and user behavior data for the Yandex Afisha entertainment platform.

## Objectives
- Analyze sales dynamics
- Study user purchasing behavior
- Compare event categories
- Identify key business metrics and trends

## Tools
Python, pandas, numpy, matplotlib, seaborn, SQL, Jupyter Notebook

## Workflow
1. Data exploration and cleaning
2. Sales and revenue analysis
3. User behavior analysis
4. Visualization and insights
