# Statistical A/B Test Analysis

## Overview
Statistical analysis and evaluation of A/B test results using hypothesis testing and exploratory data analysis.

## Objectives
- Analyze experiment results
- Compare control and test groups
- Validate statistical significance
- Interpret product metrics

## Tools
Python, pandas, numpy, scipy, matplotlib, seaborn, Jupyter Notebook

## Workflow
1. Data exploration and cleaning
2. Statistical analysis
3. Hypothesis testing
4. Result interpretation
